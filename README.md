# Portfolio Java

Este repositório contém o código-fonte do projeto Portfolio Java.

## Visão Geral

O projeto Portfolio Java é uma aplicação desenvolvida para apresentar um portfólio pessoal, destacando habilidades, projetos e experiências. A aplicação é construída utilizando Java e outras tecnologias complementares.

## Estrutura do Projeto

Separado por módulos para separar o que é do backend e frontend para aumento do meu curriculo pessoal e profissional e melhor demonstração de minhas capacidade técnicas.

## Funcionalidades

- **Apresentação de Habilidades:** Exibe as habilidades técnicas e interpessoais.
- **Projetos:** Lista de projetos com descrições e links para repositórios relevantes.
- **Experiências:** Detalhes sobre experiências profissionais e educacionais.

## Requisitos

- Java 11 ou superior
- Maven
